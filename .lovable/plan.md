

# 🎮 Retro Pixel Art Portfolio Website

A single-page portfolio with a dark, moody pixel art aesthetic inspired by games like Celeste and Hyper Light Drifter. Think dark backgrounds, neon/cyan/magenta accents, pixel fonts, and game-like interactions throughout.

---

## 🎨 Visual Theme
- **Dark background** with subtle pixel grid texture
- **Neon accent colors** (cyan, magenta, electric purple) on dark navy/black
- **Pixel font** (e.g., Press Start 2P from Google Fonts) for headings, clean font for body text
- **Pixel art decorative elements** — stars, scanline effects, glowing borders
- **CRT/retro screen effects** — subtle scanlines overlay, pixel corners on cards

---

## 📐 Sections

### 1. Hero / Landing
- Typing animation that spells out your name like a retro game title screen
- Blinking "Press Start" or "Scroll Down" prompt
- Animated pixel stars/particles in the background
- Subtitle: "First Year Engineering Student | Indie Game Enthusiast"

### 2. About Me
- Styled like an RPG character stats screen
- Your bio presented in a retro dialog box with a pixel border
- Interests and hobbies shown as "character traits" or inventory items

### 3. Skills
- Skill bars styled as pixel health/XP bars with neon glow
- Organized by category (Languages, Tools, Frameworks)
- Each skill "fills up" with an animation when scrolled into view

### 4. Projects
- Project cards styled as retro game cartridges or arcade screens
- Hover effects that "power on" the card with a glow
- Each card shows project name, description, and tech used
- Placeholder projects you can replace with your own

### 5. Contact
- Styled as a retro "Game Over → Continue?" screen
- Social links (GitHub, LinkedIn, Email) as pixel art icons/buttons
- Glowing hover effects on each link

---

## ✨ Interactive Elements
- **Typing effect** on the hero section title
- **Scroll-triggered animations** — elements fade/pixel-in as you scroll
- **Hover glow effects** on all cards and buttons
- **Smooth scrolling navigation** bar styled as a game HUD/menu bar
- **Pixel cursor** or custom cursor effect
- **Scanline overlay** for that authentic CRT monitor feel

---

## 📱 Responsive
- Fully responsive — works on mobile, tablet, and desktop
- Navigation collapses into a pixel-styled hamburger menu on mobile
